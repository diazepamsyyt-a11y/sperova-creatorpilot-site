1. Who we are and what this covers

This policy covers the SPEROVA CreatorPilot local assistant and this informational website. The maintainer is DiegoMakino; contact diajpma@gmail.com for privacy, access, correction or deletion requests. It also covers Google and YouTube API data used by the assistant. The application is currently a local-use release, not a public hosted account service.

2. Data and permissions

3. What is stored locally

The assistant stores OAuth tokens and application configuration, channel/video/playlist identifiers, metadata, reporting snapshots and exports, upload/job records, user-selected media paths, file sizes or hashes, drafts and thumbnail backups. Source video files remain in the locations you manage. Private local access links are capabilities: do not share them. Local file permissions restrict access, but do not imply that all stored files are encrypted. Optional LAN access, backups or copies on another computer require your own device and network safeguards.

4. How data is used

Data is used to identify the correct channel, execute your instructions, resume or verify jobs, display performance, estimate or read quota usage, and produce planning suggestions. Missing measurements are not treated as zero. Automatic refresh requires the local service to be running and the computer to be awake; API availability, reporting delay and authorization affect freshness. Cached reports show their dates and sources.

5. Sharing and Limited Use

Google and YouTube receive OAuth requests, API requests and media or metadata necessary for your chosen operations. Tool results, including channel information, statistics, operation results and some local paths, may be provided to Codex or your selected host so it can answer your request; the host’s own terms and data controls also apply. Tokens, passwords and private access links must not be placed in public reports or shared with unrelated services.

SPEROVA CreatorPilot’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide or improve the user-facing features you request. It is not sold, used for advertising, or used to train generalized AI models. Human access is limited to your consent, necessary security investigation, legal obligations, or permitted aggregated and anonymized internal operations. These commitments govern this application; do not assume they describe the independent host’s entire service.

6. Retention and cleanup

API observation snapshots are subject to a 30-day retention policy during local maintenance. Drafts, task records needed for recovery and user-managed source media have separate lifecycles; the 30-day rule is not a promise that every local file is automatically removed. After a definite authorization failure, a seven-day cleanup marker is recorded for affected stored account data. Cleanup runs when the local application performs maintenance, not while it is closed. Copies exported or backed up elsewhere must be removed separately.

7. Revoke access and delete data

Revoke access through your Google Account permissions. In the assistant, open “Privacy and local data / 隐私与本机数据”, review the proposed scope and confirm local deletion. Active or pending jobs can block cleanup. This privacy cleanup removes assistant-held authorizations, caches, tasks, exports and backups within its data directory; it does not delete source videos or call the YouTube video deletion API. It cannot remove data already copied to another service or device. For an individual channel or if the assistant cannot start, email the contact above with the requested scope; requests will be reviewed and processed as soon as possible and within seven calendar days after scope and identity are verified. Never email passwords, verification codes or tokens.

8. Website and hosting

These static pages contain no sign-in form, advertising tracker, third-party font, analytics script or application credential. The pages do not themselves set cookies. If hosted on GitHub Pages, GitHub logs visitors’ IP addresses for security; see the GitHub Privacy Statement. Following an external link or sending email is governed by the receiving service’s policies.

9. Changes and your choices

You may stop using the assistant, revoke access, and request access, correction or deletion. Material changes to purposes, recipients or permissions will be disclosed, with renewed consent where required. Publication of this policy does not mean the application has passed Google’s review. See also the Google Privacy Policy and YouTube Terms of Service.
